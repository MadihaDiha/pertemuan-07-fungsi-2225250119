## Cara Menjalankan Program

Pastikan Python sudah terpasang di komputer dan terminal VS Code berada di folder utama proyek.

### 1. Menjalankan File Latihan

Untuk menjalankan program salam, gunakan perintah berikut:

```bash
python latihan/01_salam.py
```

Untuk menjalankan latihan lainnya, gunakan perintah berikut:

```bash
python latihan/02_luas_persegi_panjang.py
python latihan/03_jumlah_n.py
python latihan/04_statistik_sederhana.py
python latihan/05_scope.py
```

### 2. Menjalankan Program Praktik

Jalankan perintah berikut pada terminal VS Code:

```bash
python praktik/utilitas_matematika.py
```
